# Couleurs

Les composants n'utilisent jamais une couleur directement, uniquement ces tokens. Chaque paire texte et fond atteint au moins un contraste de 4.5:1, le minimum WCAG AA. Change le thème dans la barre d'outils pour voir les valeurs sombres.
